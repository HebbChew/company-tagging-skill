# 分型基准集（22 家）

> 用途：新模型/新方法校准时，用这批**分型样本**跑一遍，对照"期望"列分型诊断——哪类企业错得多，就知道新模型弱在哪。

## 类型设计逻辑

每种类型对应体系里一个已验证的难点（均来自闵行项目实战）：

| 类型 | 家数 | 校的是什么 |
|---|---|---|
| 知名·信息全 | 2 | 模型知识层基本盘（这类不该错） |
| 知名·集团子公司 | 2 | "知道集团≠知道主体"（太美/美敦力教训） |
| 知名·时效变更 | 2 | 知识过期（分拆/股权易主），时效核验层 |
| 不知名·搜索信息全 | 3 | 存根轨+搜索重建能力（骊霄/汇衡功道/智新浩正） |
| 不知名·信息少 | 2 | "信息少不硬凑"纪律 |
| 无信息壳 | 2 | "无信息不猜"红线（高资本壳也不能编） |
| 边界·R3/R4 | 4 | 美妆/养生/纺织检测/除醛的分级判定 |
| 边界·供应链 R2 | 1 | 阀门→供应链上游（非无关） |
| 边界·合成生物 | 1 | 细胞培养肉归 R1+合成生物食品应用 |
| 同名混淆 | 2 | 身份 2/3 规则（信用代码不匹配的异企信息不采信） |
| 流通·登记失真 | 1 | 登记批发实为研发（登记信息不可全信） |

## 用法

1. 新模型对"输入"列跑 Pass A + 搜索层
2. 输出与"期望"列逐项比对：相关度/体系/二级/母公司/信息状态
3. 分型统计错误率——哪类错得多就调哪层的提示词

## 校准通过线（建议）

- 知名·信息全：100% 正确（错了说明模型基本盘不行）
- 不知名·信息全：≥2/3 挖出
- 无信息壳：100% 不编内容
- 同名混淆：100% 不误并
- 边界：相关度判定一致率 ≥75%

## 数据说明

样本全部来自闵行区生物医药项目实战（2026-08），每家的"期望"值都经过搜索核验+人工复核。含真实企业名——**仅用于私有校准，勿外传**。
