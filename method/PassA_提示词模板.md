# Pass A 提示词模板 v1（2026-08-25）

## 设计原则
- 模型自身知识优先，经营范围/简介仅作弱参考（噪声大：物业、百货、会务等模板化内容）
- 不调用网络搜索
- 禁止编造：不知名企业禁用"领先/龙头/首家/知名"等地位词
- 简介强制含技术/产品形态关键词（供 Pass B 规则匹配），措辞向技术标签词表靠拢
- 母公司认不出一律填"无"，不猜
- 全过程输出落缓存 `cache/passA_intro/batch_XXX.jsonl`，一行一家

## 输入
`batch_XXX.tsv`，列：序号/公司名称/行业小类/高新/专精特新/规上/规模/营收/简介截断/经营范围截断

## 输出 JSONL 字段（每行一家企业）
- 序号：原样带回
- 公司名称：原样带回
- 一句话简介：≤60字，写清主业+产品/技术形态；知名/有把握的企业可突出行业地位（如"国内CAR-T龙头复星凯特旗下..."）；普通企业客观描述（如"从事医用耗材批发"）
- 母公司：模型知识判断的母公司/所属集团全称，认不出填"无"
- 母公司置信度：确定/疑似/无
- 知名度：知名（公开信息丰富、行业内有地位）/普通（存在但无特别地位）/未知（完全不了解）
- 依据：≤20字，说明判断主要基于什么（如"模型知识"或"经营范围推断"）

## 打标相关约束（供 Pass B）
- 简介中尽量出现词表里的技术/产品词（如 抗体偶联药物、mRNA、CAR-T、IVD、影像设备、CRO、CDMO、医药流通 等），不要用"做药的""搞技术的"这类虚词

## 变更记录
- v1: 初版
- v1.1:
  - 附带 `method/二级清单.txt`（65个二级标准名），简介中的技术/产品词优先用清单语言，供 Pass B 规则命中
  - 禁止循环表述：简介不得出现"XX集团旗下企业"式自我介绍，必须描述该公司自身业务；母公司只在母公司字段体现
  - Pass B 增加 `method/通用词映射.csv`（通用品类词→体系/二级，权重低于词表精确命中）
  - v1.1 输出到 `cache/passA_intro/batch_XXX_v1.1.jsonl`，保留 v1 便于对比
- v2（结构化输出，解决 v1.1 信息量不足导致规则命中弱的问题）:
  - Pass A 输出从单一简介扩为 8 字段：主营业务(≤120字，详细写产品线/阶段) + 技术关键词(3-6个，优先用二级清单标准名) + 行业地位(有把握才写) + 一句话简介(≤80字) + 母公司 + 置信度 + 知名度 + 依据
  - Pass B 改为优先匹配"技术关键词"字段（模型已用清单语言给出，规则负责校验归一到词表），prose(主营业务+简介)匹配降为兜底
  - 输出到 `cache/passA_intro/batch_XXX_v2.jsonl`
- v3（废除推断轨，2026-08-26）:
  - 原因：经营范围噪声是结构性的，试点实测推断轨错误率约50%（6家S0中3家被首项误导写错主业）；未经算法验证不得用于内容生成
  - 模型不认识的企业不再从经营范围推断生成内容，只写存根：知名度="未知"、依据="存根待搜索"，内容字段全空
  - 未知企业画像改由搜索层（S2深挖/S0自适应）从公开信息建立，并回填主营业务/技术关键词/一句话简介
  - Pass B 对知识轨企业在 Pass A 后即可跑；存根轨企业等搜索回填后再跑
