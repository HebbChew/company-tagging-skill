## 一、Pass A：模型纯知识判断层（无搜索）

**这是整个体系的地基，也是用户最早提出的核心思路：先不调动网络，用大模型自己的知识扫一遍。**

### 输入（每家企业）
公司名称 + 行业小类 + 资质 flags + 规模/营收 + 经营范围(截150字) + 简介(截100字)。
后两者仅作弱参考——模型对企业有认知时用知识，无认知时才看这两列，且须在"依据"字段注明。

### 输出（分轨，JSONL 落缓存）

**知识轨**（模型认识的企业）——全字段生成：
| 字段 | 说明 |
|---|---|
| 主营业务 | ≤120字，主业/产品线/阶段/领域，信息主力字段 |
| 技术关键词 | 3-6 个，优先用词表二级清单标准名（供 Pass B 校验归一） |
| 行业地位 | 仅模型有把握时写（如"A股上市""港股01801"），无把握留空 |
| 一句话简介 | ≤80字，最终展示用 |
| 母公司 | 知识判断，认不出填"无" |
| 母公司置信度 | 确定/疑似/无 |
| 知名度 | 知名/普通 |
| 依据 | ≤20字 |

**存根轨**（模型不认识的企业，v3 起废除推断轨）——只记录客观登记字段，**不生成任何描述性内容**：
| 字段 | 说明 |
|---|---|
| 知名度 | 固定填"未知" |
| 依据 | 固定填"存根待搜索" |
| 其余内容字段 | 全部留空，由搜索层（S2深挖/S0自适应）从零建立画像后回填 |

> v3 废除推断轨的原因：经营范围噪声是结构性的（首项常无关、罗列"被允许的一切"），
> 试点实测推断轨错误率约 50%（6家S0中3家被误导写错主业）。
> 经营范围未经算法验证不得用于内容生成；未知企业的画像改由搜索层直接从公开信息建立。
> 经营范围仅保留两个合规用途：①行业小类（登记信息）作 Pass B 兜底先验 ②构造搜索词的线索。

### 实测效果（50 家经搜索全量验证后的准确度台账）

| 模型输出 | 样本 | 验证结果 | 结论 |
|---|---|---|---|
| 行业地位（敢写的） | 12 家 | 确认 11、降级 0、修正 1 | **准确率 92%，可直接采信** |
| 母公司"确定" | 18 家 | 主体不变 17、实质纠错 1（施贵宝股权变动） | **准确率 94%，可直接采信** |
| 母公司"疑似" | 6 家 | 搜索后全部落定（6→确定） | 疑似机制有效，是良好的搜索任务来源 |
| 母公司"无" | 20 家（搜索覆盖） | **8 家其实有母公司**（鱼跃/通用技术/之江药业等） | **漏检率 40%——"说没有"不可信** |
| 知名度="未知" | 10 家 | 其中多家实为高价值企业（骊霄/汇衡功道/阿尔福斯） | **"未知"≠无价值，只是模型不知道** |
| 主营业务描述 | 50 家 | 45 正确，5 被经营范围首项误导 | 准确率 90%，错误集中在"未知"企业 |

### 能力边界（一句话总结）
**高精密、低召回**：模型"知道的"很准（92-94%），"说没有的"不可靠（60% 对），"不知道的"（不知名企业）无从判断且易被噪声误导。
→ 所以 Pass A 的正确定位是：**产出初判 + 给搜索层提供分层依据**，不是终点。它把 2703 家分成"可信、待核、未知"三堆，让搜索 token 只花在刀刃上。

## 二、Pass B：规则打标层（0 token）

- 输入：「技术关键词」（主，来自 Pass A 知识轨或搜索层回填）+「主营业务+简介」prose（兜底）
- 匹配：词表 663 标签（三级名/二级名/别名，权重 3/2/3）+ 通用词映射（权重 1）+ 行业小类先验
- 技术关键词命中的标准名直接归一到词表（模型提议、规则校验，两头兼顾）
- v2.1 修正：①三级只来自三级名/别名命中（二级命中不带三级）②ASCII 关键词≥3字符整词匹配（防 DM 撞 CDMO）③关键词命中多体系时选 prose 有印证的（防非主业关键词带偏）
- 实测：残渣 0/50，置信度 高9/中41

## 三、搜索分层（脚本判定，v3 规则）

**搜索深度 ∝ 模型的无知程度（以汇报价值为门槛），而非企业名气。**

```
S2 深挖(2-3次)：知名度=普通/未知 且 有硬信号（专精特新/营收≥1亿/科创分≥90/注册资本≥1亿）
               —— "重要但陌生"，边际价值最高
S1 核验(1-2次)：知名度=知名（时效纠错）/ 母公司=疑似 / 规上
               —— 防模型知识过期（施贵宝案例），非验证真伪
S0 自适应(1次起)：其余全部 —— 1次打底，有线索（融资/集团关联/获批）代理自主追加至2-3次
```

- 已**取消零搜索层**。实证：6 家 S0 补搜 5 家有汇报级发现（骊霄=国产首款消融设备+近亿美元融资；汇衡功道=康桥资本系 mRNA 基地；阿尔福斯=福斯特旗下药企）
- 注册资本≥1亿 是低成本捞"字段空但盘子大"企业的触发器（本批 6 家 S0 中 4 家注册资本 2-3 亿）

## 四、搜索层纪律

1. 地位词分级：「全球/全国首家、第一、龙头」需权威来源（官网/招股书/交易所/权威媒体），否则降级客观描述
2. 搜不到 ≠ 有地位，禁止脑补
3. 母公司只认股权关系，不认品牌授权/经销/合作
4. 证据（来源+≤40字摘要）全部落缓存，可溯源、可复审
5. 顺带修正 Pass A 错误简介（本批纠正 5 家被经营范围误导的描述）

## 五、合并与交付

- 终稿列：序号/公司名称/**相关度**/主体系/一级/二级主/二级副/三级/标签置信度/一句话简介/行业地位/地位核验/母公司/母公司置信度/搜索层级/**信息状态**/证据(含URL)/备注/核验日期
- **相关度列（R0-R3）**：按 `method/边界识别方案.md` 分级——R0核心 / R1泛健康·合成生物非医药应用 / R2产业配套 / R3无关主业；R1-R3 必有理由，R3 必有证据URL；质检单独出**边界企业清单**
- **对账层（第二轮对抗新增）**：每个代理任务完成后脚本核对"应产序号 vs 实产序号"，缺失/解析失败的自动生成补跑清单——250+ 代理任务不允许有企业静默丢失
- **地位词最终闸门（第二轮对抗新增）**：行业地位非空但证据（URL）为空的，合并层自动清空地位或降级标"存疑"——地位词必须有据，无例外
- **母公司名称归一（第二轮对抗新增）**：合并层维护母公司别名映射表（"上药集团/上海医药/上海医药集团股份有限公司"→同一标准名），否则母公司统计碎片化
- **信息状态标签**（新列，便于筛选处理）：已核验（搜索确认/修正）/ 存疑待核（疑似未决）/ **无公开信息**（S0无信号企业：一切内容字段为空，仅登记信息可显式标注来源后呈现）/ 名单边界
- **无公开信息企业的红线**：不猜一个字——主营业务/技术关键词/行业地位/母公司全空；简介只允许写登记信息且标明来源「（登记行业：XX）暂无公开经营信息」；Pass B 对这类企业不打技术标签（仅行业小类明确指向流通/制造的保留体系级标签并标"依据=登记信息"）
- 合并层含**格式归一脚本**：简介统一句号结尾、禁"该公司/该企业"开头、统一括号与动词库、去"致力于"类套话（与提示词内嵌的标准句式范例配合，双保险统一文风）
- 简介质量标准："关键内容不错"——行业/产品/阶段/集团关系正确即可，不为措辞细节追加搜索
- 质检：体系分布、置信度分布、地位词清单（全部带证据URL）、母公司变更清单、残渣清单、抽30家标签人工复核、各代理S0+触发率异常检查、**无公开信息企业清单（单独成表交人工，按注册资本升序排列）**、**无公开信息率按注册资本分档统计**（预期几十万/几百万注册资本段大面积无信息，属正常形态而非失败）

## 七、全量执行计划（2703 家，v3 双轨流程）

### 步骤 0：切批（第二轮对抗加固）
- 批次 TSV **带全字段**：序号/公司名称/信用代码/地址/行业小类/高新/专精特新/规上/规模/营收/注册资本/科创分（地址+信用代码是身份同一性判定的原料，缺了规则执行不了）
- 切批前清洗：**信用代码去重**（源表可能有重复主体）；**登记状态过滤**（注销/吊销单列，不进主流程）
- **按集团/品牌聚类切批**（士卓曼×2、东软系×3、强生系×3 等进同一代理任务，口径一致且省搜索）
- 批次规模 **100-150 家/批**（270 家/批注意力稀释，试点验证的是 50 家规模，取折中），约 20-27 批

### 分阶段交付（第二轮对抗新增，避免长周期无产出）
| 阶段 | 内容 | 交付物 |
|---|---|---|
| Ⅰ | 步骤0切批 + 全量 Pass A v3 + Pass B + 分层 | **标签版 Excel**（标签/置信度/知名度齐全，简介母公司为模型初判版） |
| Ⅱ | 搜索 S2 深挖（约 300-400 家） | 重点企业增强版 |
| Ⅲ | 搜索 S1 核验（约 800-1000 家） | 更新版 |
| Ⅳ | 搜索 S0 自适应（约 1200-1400 家）+ Pass C + 合并归一 + 质检 | **终稿 Excel + 质检报告** |

每阶段出可交付物，任何阶段中断都有完整可用的上一阶段成果。
