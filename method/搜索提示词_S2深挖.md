# S2 深挖提示词（模型不熟但有硬信号，2-3 次搜索）

## 定位
这类企业模型不认识或只有模糊认知，但源表有硬信号（专精特新/营收≥1亿/科创分≥90/注册资本≥1亿）——**它们是搜索预算最值得花的地方**。你要从零建立企业画像。

## 搜索策略（2-3 次，按角度分配）
1. `公司全称` —— 建立基本认知+身份确认+地位线索一把抓：干什么的、什么产品、什么阶段，扫结果时同时看融资/获批/专精特新线索。**集团子公司/在华主体特别注意核实"该主体本身的职能"**（回归批教训：太美智研实为临床CRO而非母公司的SaaS、美敦力上海实为柯惠外科器械制造——主体职能与集团业务经常不同）
2. `公司全称 股东`（或 `公司全称 企查查` / `公司全称 天眼查`）—— 股权穿透：只认控股/全资/集团成员，不认品牌授权/经销/合作；**母公司名称必须写工商登记全称**（教训："海心智惠（杭州）"实为"浙江海心智惠"）
3. （第1次发现明确地位线索时）`核心产品名 获批/首创` 或 `公司全称 融资` —— 坐实地位词的等级与出处；无线索则不搜第3次

## 股权核实信源优先级（按可信度排序）
1. **权威一手**：官网投资者关系/年报/招股书/交易所公告
2. **工商聚合平台快照**：企查查/天眼查/爱企查/启信宝的股东栏快照（搜索快照即可用，但注意：①快照可能滞后，表述写"据企查查快照"②平台打的"集团标签"≠股权关系——通用赛诺案例：爱企查标"迪赛诺集团"只是关联标签，不能据此填母公司）
3. **百科**：百度百科/维基（需与 1 或 2 交叉确认）
4. **媒体报道**：仅作线索，不作股权定论依据
- 国家企业信用信息公示系统为最终权威，若搜索结果出现其页面优先采信
4. （有线索时）`核心产品名 获批/首创` —— 坐实地位词的等级与出处

## 判定与纪律
- **身份同一性**：输入文件含每家企业的地址和统一社会信用代码。采信任何搜索结果前，先确认是同一主体——全称匹配（含括号地区词）/曾用名有更名佐证/**地址与源表一致**/**信用代码一致**（快照页通常带，最强判据），至少满足 2 条；只有名字相似、有几个字一样、同城同行业 → 一律不采信，按无信息处理并在备注写"存在同名企业，已排除"
- 地位词分级："全球/全国首家、第一、龙头"需权威来源（官网/招股书/交易所/权威媒体）；只有融资稿/自媒体 → 降级为客观描述
- 发现 Pass A 简介被经营范围误导写错的（本批 10% 发生率），在备注写明正确主业，地位核验=修正
- **名单边界**：主业明显非生物医药（食品科技、工业气体、个人护理电器等，如细胞培养肉 CellX 案例）→ 备注标"名单边界-建议复核"，标签可挂"合成生物非医药应用"等补充二级
- 搜不到实质信息：保持客观，禁止脑补
- 顺带记录：重磅管线、最新融资、迁址动态（一句话进备注，带信息时点）

## 输出（JSONL 一行一家）
{"序号":int,"公司名称":str,"层级":"S2","地位核验":"确认"|"修正"|"降级"|"无补充",
 "相关度":"R0"|"R1"|"R2"|"R3"|"R4","边界理由":str,
 "行业地位_终稿":str,"母公司_原值":str,"母公司_终稿":str,"母公司置信度_终稿":"确定"|"疑似"|"无",
 "主营业务_终稿":str,"技术关键词_终稿":[str],"一句话简介_终稿":str,
 "证据":[{"来源":str,"URL":str,"摘要":str(≤40字)}],"备注":str}

- **相关度**（按 `method/边界识别方案.md`）：R0=生物医药核心主业 / R1=泛健康或合成生物非医药应用 / R2=供应链上游或产业配套平台 / R3=大健康边缘无资质（美妆/养生/食品营销） / R4=与大健康完全无关。R1-R4 必须填「边界理由」一句话；R3/R4 必须有证据URL；宁留勿冤，拿不准留较高等级
- **证据每条必须带 URL**（可回溯复核，防"搜索幻觉"）
- **主营业务_终稿/技术关键词_终稿/一句话简介_终稿**：对 Pass A 存根（未知）企业为必填——你是它们画像的唯一来源，按搜索到的公开信息写，纪律同 Pass A（技术关键词 3-6 个、尽量用二级清单标准名）；对 Pass A 已有内容的企业仅在发现错误时重写，否则照抄原值
- 一句话简介句式仿写：「科创板上市（688317）分子诊断企业，主营PCR核酸检测试剂与仪器。」/「乐普生物旗下ADC研发平台，在研管线MRG003已申报上市。」/「从事小核酸（siRNA）药物研发的创新生物科技企业。」——禁"该公司"开头、禁两句及以上
- 质量标准：求"关键内容不错"（行业/产品/阶段/集团关系正确），不为措辞细节追加搜索
- 证据 1-3 条；备注记录重要管线/融资/迁址一句话（带信息时点）
