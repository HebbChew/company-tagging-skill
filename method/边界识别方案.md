# 名单边界（相关度）识别方案 v1（2026-08-26）

> 目标：识别 P1 名单中**不属于生物医药大领域**的企业，输出相关度分级 + 边界企业清单，供名单管理决策。
> 设计依据：前 150 家（batch_001/r01/r02）实测捞出的 18 家边界案例。

## 一、边界类型学（来自实测案例）

| 类型 | 定义 | 实测案例 |
|---|---|---|
| B1a 大健康边缘（无资质） | 沾健康/消费边但无药械卫健资质 | 美妆护肤营销/零售/美容（瑞思佰/满目生香）、中医养生馆（希夷） |
| B1b 完全无关 | 与生物医药、大健康均无交集 | 纺织品检测（可泰/QTEC）、机器视觉测试（盈开，存疑待核）、教育集团跨界（山香）、个人护理电器（博朗/宝洁系） |
| B2 泛健康非医药 | 大健康相关但非医药主业 | 消费健康（科赴/小林制药中国）、保健食品（鹤延春）、新食品原料（诺安达NAG）、动物营养（祎威能/EW集团） |
| B3 产业配套与平台 | 服务产业但不做药/械/研发 | 园区开发物业（新虹桥/盛闵/南滨江）、投资管理平台（苑东投资/千健）、产业媒体（医麦客/图翎）、医药洁净工程（朗脉） |
| B4 合成生物非医药应用 | 生物技术用在食品/材料/农业 | 细胞培养肉（食未CellX）、生物基材料（凯赛）、非粮生物炼制（汉禾） |

## 二、相关度分级（终稿新列「相关度」，代替二元"是/否"）

| 等级 | 含义 | 名单处理建议 |
|---|---|---|
| **R0 核心** | 药/械/IVD/CXO/医药流通/医疗服务等生物医药主业 | 名单主体 |
| **R1 泛健康/交叉** | B2 + B4：有健康监管资质的消费健康、保健食品、动物健康、合成生物非医药应用 | 保留，标注赛道（B4 挂「合成生物非医药应用」二级） |
| **R2 配套** | B3 + 供应链上游：①医药供应链上游配套（阀门/气体/装备部件/洁净工程，挂「医药供应链上游配套」二级）②产业服务平台（园区物业/产业媒体/投资平台/非医药检测） | 保留但标注，招商口径单列 |
| **R3 大健康边缘（无资质）** | 沾健康/消费边但无任何药械卫健资质：美妆护肤（营销/零售/美容）、养生保健馆、食品营销 | 标注，名单复核观察 |
| **R4 完全无关** | 与生物医药、大健康均无交集：纺织品检测、教育集团、机器视觉（非医药应用）、个人护理电器、其他工业杂类 | **建议名单复核（候选移出）** |

## 三、识别机制（嵌入现有三层，不加新流程）

**① Pass A 知识轨（0 token）**：模型认识的非医药企业直接判（如博朗、盖米），输出「相关度」字段
**② Pass B 规则（0 token）**：只对领域相关方向打标签（流通/合成生物非医药应用/供应链上游配套）；**杂类（R3/R4：美妆/养生/纺织/教育等）不进标签库、不打领域标签**——边界判定由相关度列承载，不污染标签体系
**③ 搜索层（主力，实测 7/18 由其发现）**：错判信号触发时输出结构化字段——相关度 + 边界理由（一句话）+ 证据URL

## 四、判定纪律

1. **宁留勿冤**：不确定是否出界的，留在较高相关度（如 R1 与 R2 之间拿不准 → R1），备注写明疑点
2. **按主业判**：医药企业的多元化业务不算出界（如凯赛生物基材料 → R1，不是 R3）；集团跨界看**该主体**主业（满目生香：虽山香教育跨界，主体做美妆 → R2/B2）
3. **依据必填**：每个 R1/R2/R3 判定必须有一句话理由；R3 必须有证据URL
4. **边界企业照常完成全部字段**（标签/简介/母公司）——标边界不等于放弃画像，名单决策需要完整信息

## 五、交付

- 主表新增「相关度」列（R0/R1/R2/R3）
- 质检新增：**边界企业清单**（类型/相关度/理由/证据，单独成表）
- 分档统计：相关度分布（预期 R3 集中在小微注册资本段）

## 六、150 家实测覆盖验证

18 家边界案例的发现路径：Pass B 周边配套规则 6 家、Pass A 知识轨+搜索 4 家、搜索错判信号 8 家——三层机制均有贡献，无一层漏掉整类案例。

| 企业 | 终裁 | 说明 |
|---|---|---|

| 科赴（上海） | **R1** | 用户裁定：李施德林/邦廸等有一类械字号，有器械证的企业不判 R3 |

| 博朗（上海） | **R4** | 宝洁/吉列系剃须刀、电动牙刷等个护电器制造，与大健康无交集 → R4 |
| 希夷生物（希夷中医） | **R3** | 身份经信用代码+业态+品牌沿革交叉确认（BOSS直聘信息仅作辅助，已用工商快照与百科印证），养生馆归 R3 |

口径沉淀：①供应链上游类（阀门/气体/装备部件）一律 R2 不判 R3/R4 ②**R3 与 R4 的分界=是否沾大健康边**：美妆护肤/养生保健/食品营销（无资质但属健康消费业态）→ R3；纺织/教育/机器/电器等与大健康完全无关 → R4 ③证据不足的标"疑似+待核"不硬判 ④美妆护肤类（营销/零售/美容服务）统一 R3，不进 R1 泛健康 ⑤**泛健康与无关的分界线=健康监管资质**：有药/械/保健食品蓝帽子/新食品原料认定等药监卫健体系资质的消费健康产品（科赴、小林、鹤延春待核、诺安达）→ R1；无资质纯日化/美妆/食品营销 → R3
